# TrackFerry TV

原生 Android TV 客户端，支持 Android 6.0（API 23）及以上的电视和盒子。发版时提供两个安装包：`armeabi-v7a` 给 32 位系统，`arm64-v8a` 给 64 位系统。拿不准就先装 `armeabi-v7a`，多数 64 位系统也能运行它。

安装后在电视的「应用」里打开 TrackFerry TV，选中自动发现的服务器。电视会显示 6 位配对码和剩余有效时间，在手机的「更多 → 电视」里输入并批准。连接页也可以试听两首内置验证曲。

## 用法

- 首页上方是正在播放。按封面打开播放页，没在放时按封面就开始随便听听。右侧有「随便听听」「随机专辑」「随机歌手」三个入口。按入口本身立即开始播放，每按一次换下一张专辑或下一位歌手；按旁边的「更多」进入完整页面，在那里「换一批」。下方的「我的歌单」随歌单数量排布：四个以内铺满一行，更多时横向滚动。
- 搜索可以在飞牛曲库和在线音源之间切换，结果按歌手、专辑、歌曲分组。选一首歌，播完后会按随便听听继续接歌，不会停在只有一首的队列里。曲库里没找到时，可以一键改到在线源搜。
- 播放页的频谱取自正在解码的音频，并按出声时刻对齐，暂停时会落回静止。小鱼进度条获得焦点后，左右键每次走 5 秒，按住会加快到 10 秒、20 秒。「全屏歌词」按 0.1 秒调整当前这首歌的偏移，偏移存到服务器，网页和电视共用同一个值。
- 「音效」有原声、流行、摇滚、人声、古典、电子、低音、立体声，预设和网页一致，只作用于这台电视。小爱音箱自己解码播放，收不到音效。
- 在首页按一次返回会提示，两秒内再按一次回到桌面，音乐继续播放。要彻底停下，用「我的 → 停止播放并退出」。
- 「我的 → 应用更新」把电视上的应用升到服务器的版本。服务器从发布页取到安装包并核对签名后，电视再核对一次校验值，然后交给系统安装。第一次更新时，系统会要求允许 TrackFerry 安装应用；允许后更新会自动接着进行。任何一步失败都可以按「重试」。

默认 host 网络下，NAS 需要允许局域网访问 `18562/TCP` 和 mDNS `5353/UDP`。桥接网络或组播不可达时，在「手动连接」填 NAS 主机名或地址和 TV 端口。自定义 `TRACKFERRY_TV_LISTEN` 后，按实际端口连接。

## 构建

用 JDK 17 和 Android SDK 36 构建。版本号读自仓库根目录的 `VERSION`；versionCode 取 `主×100000 + 次×1000 + 修订×10`，再给 32 位包加 1、64 位包加 2。

```sh
./gradlew testDebugUnitTest assembleDebug lintRelease
./gradlew assembleRelease
```

正式包用 `../.private/trackferry-tv.properties` 指向的密钥签名，密钥不进 Git。缺少这份文件时，正式包不签名，`scripts/publish.sh` 也会拒绝上传。换了签名密钥后，已经装好的电视无法直接升级，只能先卸载再安装。

连接启用调试的电视或模拟器后：

```sh
adb install -r app/build/outputs/apk/debug/app-arm64-v8a-debug.apk
adb shell am start -n com.trackferry.tv/.MainActivity
```
