# 使用说明

## 音箱的三种模式

| 模式 | 会做什么 |
| --- | --- |
| 不接入 | 不读它的对话，也不控制它 |
| 观察 | 记录点歌，并写出如果接管会放什么。不出声 |
| 接管 | 曲库或线上有的歌由 TrackFerry 放，其余交给小爱 |

新发现的音箱默认不接入。能不能选接管由 `TRACKFERRY_TAKEOVER` 放行。

## 能听懂的说法

| 想做 | 可以这样说 |
| --- | --- |
| 点一首歌 | 播放周杰伦的晴天 · 我想听周杰伦唱的稻香 · 来一首后来 |
| 指定版本 | 播放晴天现场版 |
| 听一位歌手，一直放 | 我要听陈奕迅的歌 · 播放周杰伦的歌 |
| 随便听 | 放点音乐 · 随便放一首歌 |
| 接着换歌手 | 换成周杰伦的版本 · 不是这个，放邓紫棋的 · 换个版本 |
| 连播收藏 | 播放我的收藏 · 随机播放我喜欢的歌 |
| 连播专辑 | 播放专辑叶惠美 · 播放这张专辑 |
| 连播歌单 | 播放测试歌单 · 播放歌单测试 |
| 收藏正在放的歌 | 收藏这首歌 · 取消收藏 |
| 加入歌单 | 把这首歌加入测试歌单 · 从测试歌单里删掉这首歌 |
| 控制 | 暂停 · 继续 · 停止，由小爱执行，TrackFerry 跟着调整；说“停止”连播也结束；连播时还可以说下一首、上一首 |

“换版本”指 15 分钟内点过的上一首。新闻、故事、电台、闹钟等不算点歌，直接由小爱处理。管理页的“怎么说”可以输入一句话，看它被怎么理解。

## 一首歌怎么选出来

1. **曲库**：先找完全对上的。
2. **同名有多位歌手**：依次看收藏、线上对原唱的意见、匹配程度、曲库里谁的歌多。页面会写出依据，并列出其他歌手。
3. **线上**：同时问酷我、酷狗、咪咕、网易云，取最先给出的完整版。曲库和线上都没有完全对上的，再按听错一个字先曲库后线上找：歌名四个字以上可以错、多或少一个字，说了歌手的三个字就行；歌手三个字以上也可以错一个字。歌名和歌手不会同时猜，数字、“不”“没”这类字不猜。没有权限的会员歌和试听片段会跳过。在“设置 → 线上音源”用网易云音乐 App 扫码登录后，你的账号能完整听的歌也能放；这类歌不进缓存，会员到期就不再放。扫码提示要额外验证（8821）时，点“粘贴凭据”：在电脑浏览器登录 music.163.com，按 F12 复制 Cookie 里 MUSIC_U 的值贴进来。
4. **小爱**：前面都没有，或说的不是点歌，就由小爱处理。

## 放歌时

- 音量会短暂归零再恢复，这是为了不漏出小爱自己的播放。程序意外退出，下次启动会补上恢复。
- 和小爱说别的话，歌会停下，等小爱说完从断点接着放。
- 说“暂停”后，说“继续播放”回到断点；说“停止”就结束，连播也一起结束。小爱去放了别的内容，歌不会再自动续上。
- 页面上的播放、暂停、停止和说话效果一样，在“此刻”选中音箱，或到音箱页操作。
- 点一首歌，放完即停。点歌手、收藏和歌单会一首接一首放，默认随机，全部放过一遍后重新打乱接着放。
- 播放方式在“此刻”或音箱页切换，每台音箱各记各的：随机播放、顺序循环、单曲循环。单曲循环对点的单首歌也有效，同样受“最长放多久”限制；改了方式，正在放的这首不受影响。口令点的歌单先随机挑一首开始，顺序循环时从它往后按顺序放。
- 上一首、下一首可以点按钮，也可以说。放的是单曲时，下一首从飞牛曲库随机换一首。小爱自己放的内容不能用按钮切。

- **拖进度**：在“此刻”拖进度条，或点一句歌词，就从那里接着放。音箱要重新取流，会停顿一两秒；FLAC、MP3、WAV 能拖，M4A 在音箱上不能。
- **播放列表**：点操作区右边的列表图标，看正在放的和后面的歌，点一首就放它，点叉移出，也可以停止播放。移出只影响这次播放，不动飞牛的歌单和音乐文件。
- **歌词**：点歌词右下角可以换字号；对不上时提前或延后，这首歌以后都按它来。

## 在本机放

选音箱时选“本机”，歌就在当前打开页面的手机或电脑上放，不经过小爱。没选过音箱时，搜索和曲库默认放在本机。从专辑、歌单、收藏、歌手里点一首，就从这首起放这一列；从搜索里单点一首，后面接着随机放曲库里的歌。

- 曲库、搜索、收藏、歌单、专辑都能放到这里，随机、循环、单曲循环和播放列表都有，锁屏上也能暂停和切歌。
- 每个浏览器各放各的，列表记在浏览器里，刷新后停在原来的地方。
- 不写进点歌记录，也不影响音箱。iPhone 不允许网页调音量，用侧边的音量键。
- 关掉页面就停。

## 连续播放

在“设置 → 连续播放”里：

| 选项 | 默认 | 作用 |
| --- | --- | --- |
| 点歌手时一直放 | 开 | 说“播放周杰伦的歌”，曲库里这位歌手的歌随机连播；关掉就只放一首 |
| 点完一首接着随机放 | 关 | 点的歌放完，从飞牛曲库随机接着放 |
| 最长放多久 | 3 小时 | 所有连播到时间就结束，正在放的那首会放完；可以设为不限 |

## 从页面送歌到音箱

- **收藏、歌单、专辑、歌手**：在曲库页点旁边的播放键，选一台音箱，按它的播放方式连播。音箱设为观察或接管都可以。
- **下一首放**：曲库和搜索里，点歌右边的三个点，选音箱后点“下一首放”。放完现在这首就放它，不打断正在放的。
- **名字难念、识别不准的歌**：在搜索页点“在线源”，搜酷我、酷狗、咪咕、网易云，点一下就送到音箱。送过的歌照常缓存，靠会员放的除外。

## 压住小爱的回答

接到点歌时先打断小爱，同时把音量降到零遮住打断生效前的那一小段。接管的音箱在音箱页可以换档，型号不支持米家静音的没有“加强”：

| 档位 | 做法 |
| --- | --- |
| 普通 | 音量调到零并打断，出歌最快 |
| 加强 | 再加一道米家静音和暂停。LX06 没有这一档，OH2P 默认用这一档 |
| 等小爱说完 | 一直静音，估计小爱说完了再放歌，出歌慢一些 |

普通压不住就换加强，没有这一档或还不行就换等小爱说完。小爱的话要先被读到才能打断，开头漏一点点属于正常。

## 曲库多久同步一次

默认每 6 小时，在“设置 → 飞牛音乐”里可以改成 5、15、30 分钟或 1、3、12、24 小时，或关掉只手动同步。没有变化时只读一遍列表，不写数据库，常加歌选 5 分钟也没有负担。

## 收藏和歌单

- 读的是设置里登录的飞牛音乐账号的收藏和歌单，说的时候现读，刚加进去的也算；但歌要已经同步到曲库。
- 歌单名要说出“歌单”两个字。完全一致的优先，其次是名字里包含所说的，三个字以上允许听错一个字。只有一个歌单时可以不说名字。
- 中途暂停、和小爱聊天，继续后照样连播。说“停止”、点别的歌、让小爱放别的内容、从页面推歌、把音箱改为不接管，连播就结束。停了 15 分钟不再续。
- 放不了的歌自动跳过；连着三首音箱都没有放出来就停下。
- 程序重启后连播不会自动恢复，再说一次即可。
- 加入、移出只改飞牛音乐的歌单，不动音乐文件。线上找来的歌不在飞牛曲库里，加不进去。

## 管理页

| 页面 | 内容 |
| --- | --- |
| 此刻 | 正在放的歌、歌词、进度和播放列表；按天的点歌记录，手机上点右下角的图标打开；试一句看会放什么，不出声 |
| 流转 | 一句话的全过程，实时或回放 |
| 怎么说 | 说法示例与解释，以及不用说话的操作从哪里点 |
| 搜索 | 曲库和在线源，点一下送到音箱 |
| 曲库 | 收藏、歌单、专辑、歌手，送到音箱或排到下一首 |
| 音箱 | 模式、状态、压住小爱的方式、播放暂停停止、音量、唤醒、接管测试 |
| 设置 | 账号、音源、连续播放、Home Assistant、密码、更新 |

登录时勾上“保存密码”，密码交给浏览器自己的密码库保存，180 天内不用再登录；不勾的话关掉浏览器就要重新登录。公用电脑上不要勾。

## 装到手机或电脑桌面

- **iPhone、iPad**：用 Safari 打开，分享 → 添加到主屏幕。1.5.0 之前添加过的，删掉图标重新添加一次，水面才会铺到状态栏下面。
- **安卓、电脑的 Chrome 或 Edge**：用 HTTPS 地址打开时，“设置 → 关于”会出现“装到桌面”。用 http 的局域网地址，浏览器不允许安装，只能添加快捷方式。
